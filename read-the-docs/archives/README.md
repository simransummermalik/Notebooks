# Documentation archives

The PyGAGE documentation packages are grouped under the date they were built:
[`pygage/2026-07-29/`](pygage/2026-07-29/).

- `baseline/` contains the original supplied Sphinx website archive.
- `preview/` contains the updated generated website archive.
- `handoff/` contains the source-review package and the complete ZIP bundle.

The accidentally named `].zip` file was a valid archive. It was renamed to
`pygage-docs-complete-update-2026-07-29.zip` so its purpose is clear.
