# Pathview Plus documentation and validation workspace

This repository is organized by date and by project. Use the folder that
matches the work you need to read or rerun.

## Main folder map

| Folder | Label | What is inside |
|---|---|---|
| [`08-10-2026/`](08-10-2026/) | **Original August 10 audit** | The first Pathview Plus/PyGAGE validation notebooks, saved inputs, pathway images, test results, and the initial R-versus-Python Pathview check. |
| [`08-11-2026/`](08-11-2026/) | **R comparison — August 11** | The updated Pathview Plus 3.1.0 comparison with R Pathview and R SBGNview, including the executed Jupyter notebook, figures, scripts, reports, and proof files. |
| [`08-12-2026/`](08-12-2026/) | **Pathview-only follow-up — August 12** | The follow-up from the August 10 bug list. It tracks all 86 old findings as fixed, still reproducible, or changed in Pathview Plus 3.1.0. |
| [`08-13-2026/`](08-13-2026/) | **Paper update — August 13** | The new source-level feature, API, and argument comparison files, figures, summary data, and notes for updating the paper. |
| [`pygage-pathview-validation/`](pygage-pathview-validation/) | **Separate validation workspace** | The larger local PyGAGE and Pathview validation package, including its own notebooks, scripts, reports, tests, results, and archive files. |
| [`read-the-docs/`](read-the-docs/) | **Read the Docs projects** | The standalone beginner Pathview Plus documentation, the separate PyGAGE MkDocs documentation, Sphinx handoff files, previews, and archived website packages. |
